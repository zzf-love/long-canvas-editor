# 使用指南

## 连续画布和分屏

中间画布是完整长图；左侧分屏用于定位和管理。分屏可以新增、复制、删除和调整顺序。元素跨过分屏边界时，预览和导出保留连续内容。

选中分屏后，在右侧修改高度，或开启“调节底边”拖动分屏底边。后续分屏会整体顺移，当前屏的前景文字和图片保持原尺寸。背景层默认锁定，可先在图层面板解锁。

## 文字、图片和图层

双击文字后编辑内容，也可以在属性面板修改字号、行高、字距、字重和颜色。图片支持 PNG、JPEG、WebP；图中已经存在的文字属于图片像素，无法像文字层一样编辑。

按住 Shift、⌘ 或 Ctrl 可多选。点击“链接”后，一起移动、缩放和对齐；Alt 点击某个链接成员可单独微调。图层列表越靠上越在前，拖动图层或使用排序按钮调整遮挡。

不透明度支持 0–100%，多选时一起调整。完整图标应作为一个图形组或一张透明图片导入，以便后续整体编辑。

## 对齐、参考线和复制

从标尺拖出参考线。右侧属性可以编辑其位置；双击或拖出画布可以删除。开启吸附后，元素会吸附到参考线、画布边缘和其他元素；Alt 暂时关闭吸附。

对齐可以以当前分屏或选区为基准；至少三个独立选择单元可等距分布。坐标使用整张长画布的位置，分屏切换不会使 Y 坐标归零。

复制元素后，点击目标分屏再粘贴。样式、透明度和内部链接会保留，新副本与原对象独立。剪贴板用于当前编辑器会话，刷新后需要重新复制。

## 保存、恢复和导出

“保存工程”导出完整 JSON，其中包含工程结构、文字、图层和图片素材。下次通过“打开工程”载入。自动保存存放在当前浏览器的 IndexedDB；清理浏览器数据、切换浏览器或切换访问地址会影响恢复。

“操作帮助”中的恢复示例功能支持撤销。重要版本仍建议先下载工程文件再操作。

| 导出项 | 结果 |
| --- | --- |
| 当前屏 PNG | 从连续画布裁取当前屏范围，包括跨屏的可见内容 |
| 完整长图 PNG | 完整 790 px 宽的连续长图 |
| 当前屏 SVG | 保留文字与图形，并嵌入图片素材 |

以上导出不含选框、标尺、参考线。PNG 和 SVG 用于交付；继续编辑请保留工程 JSON。过长画布可改为逐屏导出。

## 脚本协作

构建并启动本机服务后，浏览器存档会镜像到 `.local-data/`。脚本提交的改稿仅排队，点击“应用最新改稿”才会修改画布。同一分屏在取稿之后发生变化时，更新会被拒绝，避免覆盖手动编辑。每次应用都是一个可撤销步骤。

命令和数据格式见 [本机协作协议](local-bridge.md)。
